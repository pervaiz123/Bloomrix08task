Modern Layout . 01

Flexbox: one-dimensional layout

Flexbox arranges items along a main axis and a cross axis. It is ideal for one-dimensional rows or columns, navigation, toolbars, centered content, form rows, and equal-height components.

Flex Container

The parent with display: flex controls the layout of its direct flex items.

Flex item

Each direct child of a flex container becomes a flex item.

Main Axis

The primary direction set by flex-direction, such as row or column.

Cross axis

The axis perpendicular to the main axis; align-items controls alignment across it.

Flex container and flex item properties Try changing flex-flow, gap, order, grow, shrink, basis, or alignment values.

Grid creates rows and columns. Tracks are the spaces between grid lines, and their intersections form cells. Grid areas let you name and position related sections of a layout.

Current module · HTML and CSS

From page structure to responsive interfaces

Start with semantic HTML elements, then use CSS to control how content looks and responds to different screen sizes. Modern layouts make pages easier to maintain and adapt.

  1. Build the structure. Use headings, paragraphs, links, lists, forms, and tables with meaningful semantics.
  2. Style the interface. Apply selectors, typography, spacing, color, borders, and the box model.
  3. Arrange the content. Use Flexbox for one-dimensional alignment and Grid for rows and columns.
  4. Make it responsive. Start with a mobile layout, then add breakpoints where the content needs more room.
